Teoria — Sistemas Lineares

Resumo dos conceitos fundamentais para resolver e classificar sistemas de equações lineares.

DEF Sistema de equações lineares

Um sistema de m equações e n incógnitas tem a forma Ax = b, onde A é a matriz dos coeficientes (m×n), x = (x₁,…,xₙ)ᵀ é o vetor das incógnitas, e b = (b₁,…,bₘ)ᵀ é o vetor dos termos independentes.
A matriz aumentada [A|b] junta A e b numa única matriz (m×(n+1)).

DEF Sistemas homogéneos vs. não-homogéneos

Se b = 0, o sistema é homogéneo — tem sempre a solução trivial x = 0.
Se b ≠ 0, é não-homogéneo — pode ser impossível, determinado ou indeterminado.

THM Teorema de Rouché-Capelli

Seja r = car(A) e r' = car([A|b]):
• Se r' > r → Sistema Impossível (SI) — sem solução.
• Se r' = r = n → Sistema Possível Determinado (SPD) — solução única.
• Se r' = r < n → Sistema Possível Indeterminado (SPI) — infinitas soluções (n − r graus de liberdade).

MÉTODO Eliminação de Gauss-Jordan

Opera sobre a matriz aumentada [A|b] usando três operações elementares por linhas:
L_i ↔ L_j Trocar duas linhas
L_i ← k·L_i Multiplicar uma linha por k ≠ 0
L_i ← L_i + k·L_j Somar a uma linha um múltiplo de outra

O objetivo é obter a forma escalonada reduzida por linhas (RREF): cada linha com pivô tem 1 nessa posição e 0 em todas as outras entradas da mesma coluna.

PASSO A PASSO
  1. Escolher o pivô — primeiro elemento não-nulo da coluna mais à esquerda.
  2. Se necessário, trocar linhas para colocar o pivô na linha atual.
  3. Normalizar a linha do pivô: dividir toda a linha pelo valor do pivô → pivô fica 1.
  4. Eliminar a coluna do pivô: subtrair múltiplos da linha do pivô a todas as outras linhas.
  5. Avançar para a próxima coluna/linha e repetir.
  6. Ler a solução: se SPD, x_i = valor na coluna b da linha i.
SPD Sistema Possível Determinado

car(A) = car([A|b]) = n (nº de incógnitas).
A forma escalonada não tem linhas do tipo [0 0 … 0 | c≠0] e tem exatamente n pivôs.
Solução única: x = A⁻¹b

SPI Sistema Possível Indeterminado

car(A) = car([A|b]) = r < n.
Existem n − r variáveis livres (parâmetros). A solução geral é uma família de soluções parametrizada por esses parâmetros.

SI Sistema Impossível

car([A|b]) > car(A).
Na forma escalonada existe pelo menos uma linha do tipo [0 0 … 0 | c≠0], que representa a equação 0 = c (contradição).
Não existe qualquer solução.

DEF O que é a Regra de Cramer?

A Regra de Cramer é um método algébrico para resolver sistemas lineares quadrados (n×n) onde a matriz dos coeficientes A é invertível (det(A) ≠ 0).

Para cada incógnita xᵢ, constrói-se uma nova matriz Aᵢ: copia-se A e substitui-se a coluna i pelo vetor dos termos independentes b.

A solução é dada diretamente por:
xᵢ = det(Aᵢ) / det(A)

PASSO A PASSO Como aplicar
  1. Escreve o sistema na forma matricial Ax = b.
  2. Calcula det(A). Se for 0, o método não se aplica — usa Gauss-Jordan.
  3. Para cada incógnita xᵢ (i = 1, …, n):
      → Cria Aᵢ substituindo a coluna i de A pelo vetor b.
      → Calcula det(Aᵢ).
  4. Calcula xᵢ = det(Aᵢ) / det(A).
EXEMPLO Sistema 2×2 explícito

Sistema:
  a₁x + b₁y = c₁
  a₂x + b₂y = c₂

Passo 1 — det(A):
  D = det(A) = a₁b₂ − b₁a₂

Passo 2 — det(A₁): substitui coluna 1 por b
  D₁ = det(A₁) = c₁b₂ − b₁c₂
  x = D₁ / D

Passo 3 — det(A₂): substitui coluna 2 por b
  D₂ = det(A₂) = a₁c₂ − c₁a₂
  y = D₂ / D

DETERMINANTES Como calcular — métodos por dimensão
2×2 — Fórmula direta:
det([[a,b],[c,d]]) = ad − bc

3×3 — Regra de Sarrus:
det = (a₁₁·a₂₂·a₃₃ + a₁₂·a₂₃·a₃₁ + a₁₃·a₂₁·a₃₂)
− (a₁₃·a₂₂·a₃₁ + a₁₁·a₂₃·a₃₂ + a₁₂·a₂₁·a₃₃)
(Diagonais principais positivas, diagonais secundárias negativas)

n×n — Expansão de Laplace (cofatores):
det(A) = Σⱼ aᵢⱼ · Cᵢⱼ, onde Cᵢⱼ = (−1)^(i+j) · det(Mᵢⱼ)
Mᵢⱼ é a submatriz obtida removendo a linha i e a coluna j.
QUANDO USAR Cramer vs. Gauss-Jordan
✓ Cramer é útil quando…
  • O sistema é 2×2 ou 3×3
  • Só precisas de uma incógnita específica
  • Trabalhas com sistemas simbólicos/paramétricos
  • Precisas de uma expressão fechada para a solução
✗ Usa Gauss-Jordan quando…
  • O sistema é maior (4×4 ou mais)
  • det(A) = 0 (SI ou SPI)
  • O sistema não é quadrado (m ≠ n)
  • Precisas de maior eficiência computacional
